# FCT Technologies

FCT Technologies is a founder-led software company in Elgin, Illinois. We build marketing websites, web and mobile applications, AI integration and automation, GEO/SEO systems, Second Brain OS, and custom AI harnesses: software a business can use, inspect, and own.

## Public work

- **[Villain Arc](https://fct-technologies.com/projects/villainarc/)** — native iOS strength-training app, live on the App Store. SwiftUI, SwiftData, CloudKit, HealthKit, App Intents, Widgets, Live Activities, and on-device Foundation Models behind its progression suggestions.
- **[TranscriptionStudioApp](https://github.com/fcttechnologies/TranscriptionStudioApp)** — native macOS and iPhone transcription with on-device speaker diarization: WhisperKit for speech, NVIDIA Sortformer on the Apple Neural Engine. Nothing leaves the machine. Source-available.
- **[TranscriptionStudio](https://github.com/fcttechnologies/TranscriptionStudio)** — the open-source web engine the native app grew from, still running headless behind FCT's own workflows. FastAPI and Faster-Whisper, local-first, MIT.
- **[VoicePipeline](https://github.com/fcttechnologies/VoicePipeline)** — rights-cleared audio preparation and model-training pipeline for custom text-to-speech work.
- **[fct-technologies.com](https://fct-technologies.com/)** — the Astro and Cloudflare site FCT keeps as its own working proof surface for SEO and GEO.

## What we build

- **Second Brain OS** — a file-based AI workspace the business owns, wired into the tools it already runs
- **Custom AI Harness** — the runtime itself, engineered for a company rather than bought off a shelf
- **Marketing websites** — technical SEO, schema, and AI-search answer structure built in
- **Web and mobile applications** — Next.js and React on the web, native SwiftUI on Apple platforms
- **AI integration and automation** — gated where trust matters, measured rather than trend-driven
- **GEO-SEO** — a composite score moved month over month against the same rubric
- **Software consulting** — build, buy, vendor, and architecture decisions

We run what we sell: FCT's own operations run on the same workspace and harness we install for clients.

Based in Elgin, Illinois. Serving Chicagoland and remote clients.
